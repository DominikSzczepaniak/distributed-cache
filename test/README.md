This folder is for tests.
There are 4 types of tests:
1. Integration - tests that involve multiple nodes and tests that they are communicating correctly. Basically they test inter-component interactions.
2. E2E - tests that simulate client running the cluster.
3. Benchmarks - self explainatory. Compared against single computer.
4. Fault injections - tests that check whether system will behave correctly after some bad events e.g. leader killed.
